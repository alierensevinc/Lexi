# YDS Kelime & Soru Bankası — Official Website

Static landing page, privacy policy, and `app-ads.txt` for the **YDS Kelime & Soru Bankası** iOS application.

- `index.html`: Feature overview and tech stack for the 3,301-word vocabulary trainer and 4,224-question YDS Question Bank.
- `privacy-policy.html`: App Store privacy policy detailing local on-device storage (SQLite + MMKV) and AdMob usage.
- `app-ads.txt`: Authorized Digital Sellers declaration for Google AdMob.
